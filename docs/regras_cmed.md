# Regras CMED para Pregões — RJ

## 1. CAP
O CAP vigente a partir de 24/09/2026 é de 19,79%, conforme Resolução CTE-CMED nº 1, de 25/05/2026.

O percentual não deve ser aplicado indistintamente a todos os medicamentos. Primeiro deve ser verificado se o produto integra o rol sujeito ao CAP ou se a aquisição decorre de decisão judicial.

## 2. Teto para compra pública
- CAP SIM → PMVG.
- CAP NÃO + sem decisão judicial → PF.
- Decisão judicial → PMVG.

## 3. ICMS
A lista CMED disponibiliza valores por diferentes alíquotas de ICMS. Para uma conferência correta, deve-se selecionar a coluna correspondente à tributação aplicável à operação.

## 4. Campos da base
GGREM; princípio ativo; medicamento; laboratório; apresentação; CAP; ICMS RJ; PF RJ; PMVG RJ; preço ofertado; desconto sobre teto; situação; data da lista; fonte.

## 5. Controle
A base deve guardar a data da tabela CMED utilizada, pois os preços são atualizados e a análise do pregão deve ser vinculada à lista vigente na data de referência.
